# Helber Soares Portfolio

Recruiter-focused portfolio built with React, TypeScript and Vite.

## Routes

- `/` - English-first bilingual homepage for recruiters.
- `/resume` - ATS-friendly resume page with plain, printable content.
- `/projects` - technical project briefing for interviewers.

## Stack

- React
- TypeScript
- Vite
- Vitest
- React Testing Library
- lucide-react

## Commands

```bash
pnpm install
pnpm test
pnpm run build
pnpm run dev
```

## Content Sources

Content is based on Helber's GitHub profile, public repositories, project READMEs and LinkedIn profile. The strongest projects are curated for recruiters and interviewers instead of presenting every repository with equal weight.
